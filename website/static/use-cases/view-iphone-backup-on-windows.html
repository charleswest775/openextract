View an iPhone backup
on Windows.

Windows keeps iPhone backups in a folder called MobileSync\Backup: either %USERPROFILE%\Apple\MobileSync\Backup (the Apple Devices app, or iTunes from the Microsoft Store) or %APPDATA%\Apple Computer\MobileSync\Backup (iTunes downloaded from Apple's website). The files inside aren't readable on their own, so open the folder with a backup viewer such as OpenExtract (free) to read the messages, photos and everything else.

You'll find the folder in a minute. What's in it will look like nonsense, and that's normal: Apple renames every file in a backup to a long code and keeps a database that maps the codes back to real names. A viewer reads that database for you.

01

Open the backup folder

Press the Windows key and R together, paste %USERPROFILE%\Apple\MobileSync\Backup and press Enter. If Windows can't find it, try %APPDATA%\Apple Computer\MobileSync\Backup. If neither exists, this PC has no iPhone backup in the usual place.

02

Recognize a backup

Each backup is one folder with a long name of letters and numbers, which is the device's ID. Inside are files called Manifest.db, Info.plist and Status.plist, and many folders with two-character names. The folder's date modified tells you roughly when it was last backed up.

03

Leave the inside alone

Don't rename, open or edit anything in the backup folder. To move or keep a copy, copy the whole folder, for example to an external drive.

04

Install OpenExtract

Download it for Windows and run the installer. It's free and needs no account.

05

Open the backup in OpenExtract

Choose Explore my data and pick the Backup folder, or one backup folder inside it. If there's more than one, OpenExtract lists each with the device name, iOS version and date. A lock means it's encrypted, and you'll be asked for the backup password.

06

Read what's inside

Use the tabs: Overview, Timeline, Messages, Photos, Contacts, Calls, Notes, Voicemail and History. Export anything you want to keep as ordinary files.

What it can't do

  • iCloud backups aren't on your PC. OpenExtract reads backups saved on a computer.
  • An interrupted backup may be incomplete. If a backup stopped partway, some things may be missing. Back up again to get a full one.
  • Encrypted backups need their password. There's no way to open one without it.
  • It doesn't change where backups are saved. Apple's apps choose that folder. OpenExtract can open a copy from anywhere, though.

Common questions

Why can't I just open the files in the backup? Apple stores the data in databases and renames every file to a code, so there's nothing to double-click. A viewer reads the database and shows the real content.

Can I move the backup to another drive? You can copy the whole folder anywhere and open the copy in OpenExtract. Apple's apps only look in their usual folder, so leave the original there if you want them to keep using it.

Which backup belongs to which phone? OpenExtract shows each backup's device name, iOS version and date when you pick the folder that holds them.

Does it open iPad backups? Yes. iPad backups use the same format.

Does anything get uploaded? No. OpenExtract reads the backup on your own computer and doesn't send it anywhere. The only thing it asks the internet for is whether a new version is out, and it asks you before it checks. You can turn that off in Settings.

Is it really free? Yes. OpenExtract is open source under the MIT license, with no paid tier. The code is on GitHub.
