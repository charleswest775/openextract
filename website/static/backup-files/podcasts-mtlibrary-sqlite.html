What it holds

MTLibrary.sqlite is the Podcasts app's library, in its app group. ZMTPODCAST has one row per show the app knows about; followed shows have ZSUBSCRIBED set to 1. ZMTEPISODE has every episode the app has seen in each show's feed, with its play count and when it was last played.

The downloaded audio isn't in the backup. Episodes point into the phone's Media/Podcasts folder, which iPhone backups leave out.

Key columns

  • ZMTPODCAST.ZTITLE: The show's name.
  • ZMTPODCAST.ZFEEDURL: The show's RSS feed.
  • ZMTPODCAST.ZSUBSCRIBED: 1 for a show the owner follows.
  • ZMTEPISODE.ZTITLE: The episode's title.
  • ZMTEPISODE.ZPLAYCOUNT: How many times it was played.
  • ZMTEPISODE.ZLASTDATEPLAYED: When it was last played.

Tables by iOS version

iOS 13.3.1 has 16 tables:

ZMTCATEGORY, ZMTEPISODE, ZMTPLAYLIST, ZMTPODCAST, ZMTPODCASTCATEGORY, ZMTPODCASTPLAYLISTSETTINGS, ZMTSYNCINFO, ZMTTHEME, ZMTUPPMETADATA, Z_2ADDEDTOPLAYLISTS, Z_2PLAYLISTS, Z_2SETTINGS, Z_3PODCASTS, Z_METADATA, Z_MODELCACHE, Z_PRIMARYKEY

Then, version by version:

  • iOS 13.4.1 (16 tables): the same as iOS 13.3.1.
  • iOS 16.1.2 (20 tables): adds ACHANGE, ATRANSACTION, ATRANSACTIONSTRING, ZMTCHANNEL, ZMTOFFLINEKEYDATA, Z_4PODCASTS; drops ZMTCATEGORY, Z_3PODCASTS.
  • iOS 17.3 (20 tables): the same as iOS 16.1.2.

How to open it

Free, in OpenExtract. Open the backup in OpenExtract and choose Podcasts. OpenExtract lists the shows followed and your listening history, and saves the subscriptions as an OPML file other podcast apps can import. Step by step: Export podcasts from an iPhone backup.

By hand. In a backup that isn't encrypted, 39/398be25b8d2881e4a18865f018eb5d8e3c8fc962 is an ordinary SQLite database with no extension. Copy it out of the backup folder and open the copy with any SQLite browser, such as DB Browser for SQLite. Work on a copy: changing anything inside a backup can stop it from restoring.

In an encrypted backup, the file in the backup folder is encrypted with a key of its own, which only the backup password unlocks, so nothing can open it until it's decrypted. OpenExtract does that when you open the backup and type its password.
