Where are iPhone
backups stored?

On a Mac, iPhone backups are in ~/Library/Application Support/MobileSync/Backup. On Windows they're in %USERPROFILE%\Apple\MobileSync\Backup or, with older iTunes, %AppData%\Apple Computer\MobileSync\Backup. Each phone gets one folder with a long code for a name. Here's how to get there, tell the folders apart, and read one.

01

On a Mac

In Finder, choose Go, then Go to Folder, paste ~/Library/Application Support/MobileSync/Backup/ and press Return. Finder makes backups on macOS Catalina and later; iTunes used the same folder before that.

Or let Finder take you there: connect the iPhone, select it in the Finder sidebar, click Manage Backups on the General tab, right-click a backup and choose Show in Finder.

02

On Windows

Press the Windows key and R together, paste %USERPROFILE%\Apple\MobileSync\Backup and press Enter. That's where the Apple Devices app and iTunes from the Microsoft Store keep backups. If Windows can't find it, try %AppData%\Apple Computer\MobileSync\Backup, where iTunes downloaded from Apple's website keeps them.

Apple Devices and iTunes can also take you there: Manage Backups, right-click a backup, Show in Explorer. For the full walk-through, see view an iPhone backup on Windows.

03

Tell the backups apart

Each folder in Backup is one device, named after its ID. Inside are Manifest.db, Info.plist, Status.plist and many folders with two-character names. The date modified tells you roughly when it was last backed up. Manage Backups in Finder or Apple Devices lists each one by device name and date, and so does OpenExtract when you open the Backup folder.

04

Keep it safe

Don't rename, open or edit anything inside a backup, or Apple's apps may no longer restore it. The next backup of the same phone updates the folder, so to keep one as it is, choose Archive under Manage Backups, or copy the whole folder to another drive. Apple notes that a deleted backup can't be recovered.

05

Read what's in it

The files themselves won't open: Apple renames each one to a code. OpenExtract is a free, open-source viewer for Windows, Mac and Linux that finds backups in these folders on its own, or opens a copy from anywhere. You can read and save messages, photos, contacts, calls, notes, voicemail and web history. An encrypted backup needs the password you set for it.

On Linux

Apple makes no backup app for Linux, so there's no standard folder. Copy a backup folder over from a Mac or PC, or make one with the idevicebackup2 tool, and open it from wherever you saved it. See iPhone backups on Linux.

Not here: iCloud backups

A backup to iCloud isn't saved on any computer, so none of these folders will have it. OpenExtract reads backups saved on a computer only. To make one, connect the iPhone by cable and back up in Finder, the Apple Devices app or iTunes, or with OpenExtract itself.

Common questions

Are iCloud backups stored on my computer? No. An iCloud backup stays in iCloud, and the folders on this page only hold backups made by a cable connection to a Mac or PC. To see which phones have an iCloud backup, open Settings on the iPhone, tap your name, then iCloud, then iCloud Backup.

Can I move my backups to another drive? You can copy a backup folder anywhere, for example to an external drive, and open the copy in OpenExtract. Finder, iTunes and Apple Devices only look in their usual folder, so leave the original where it is if you want them to keep using it.

Will the next backup replace this one? Yes. Each new backup of the same phone updates its folder. To keep one as it is, choose Archive under Manage Backups, or copy the whole folder somewhere else first.

Why are there several folders in Backup? Each folder is one device: an iPhone or iPad backed up on this computer. An archived backup gets a folder of its own.

Why does my Mac say I don't have permission? macOS protects the folder that holds backups. Finder can show it, but other apps, OpenExtract included, need Full Disk Access: open System Settings, then Privacy & Security, then Full Disk Access, and turn the app on.

Can I open the files in a backup? Not directly. Apple renames every file to a long code and keeps a database, Manifest.db, that maps the codes back to real names. A viewer such as OpenExtract reads that database and shows the messages, photos and other data as they were on the phone.

Apple's own instructions are on Locate and manage backups of your iPhone, iPad and iPod touch.
