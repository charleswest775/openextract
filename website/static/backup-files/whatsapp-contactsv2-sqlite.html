What it holds

ContactsV2.sqlite pairs WhatsApp IDs with names from the phone's address book, in ZWAADDRESSBOOKCONTACT.

It comes from older WhatsApp versions. The two newest backups we checked (iOS 16.1.2 and 17.3) don't have it; they have LID.sqlite instead.

Key columns

  • ZWAADDRESSBOOKCONTACT.ZWHATSAPPID: The person's WhatsApp ID.
  • ZWAADDRESSBOOKCONTACT.ZFULLNAME: Their name in the phone's address book.

Tables by iOS version

The same 4 tables in every backup we opened (iOS 13.3.1, 13.4.1 and 15.3.1):

ZWAADDRESSBOOKCONTACT, Z_METADATA, Z_MODELCACHE, Z_PRIMARYKEY

How to open it

Free, in OpenExtract. Open the backup in OpenExtract and choose WhatsApp. OpenExtract uses it to put names on the people in WhatsApp chats. Step by step: Export WhatsApp chats from an iPhone backup.

By hand. In a backup that isn't encrypted, b8/b8548dc30aa1030df0ce18ef08b882cf7ab5212f is an ordinary SQLite database with no extension. Copy it out of the backup folder and open the copy with any SQLite browser, such as DB Browser for SQLite. Work on a copy: changing anything inside a backup can stop it from restoring.

In an encrypted backup, the file in the backup folder is encrypted with a key of its own, which only the backup password unlocks, so nothing can open it until it's decrypted. OpenExtract does that when you open the backup and type its password.

Related files

  • ChatStorage.sqlite: WhatsApp's chats: every message, group and call on the phone, with pointers to its photos, videos and voice messages.
  • LID.sqlite: WhatsApp's LIDs, the IDs newer WhatsApp versions use instead of phone numbers, matched to numbers and names.
