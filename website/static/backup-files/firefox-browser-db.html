What it holds

browser.db is the history database of older Firefox for iOS versions. history has one row per web address and visits one row per visit.

Newer versions keep history in places.db, next to it. A backup can have both.

Key columns

  • history.url: The web address.
  • history.title: The page's title.
  • visits.siteID: Which address was visited: its id in history.
  • visits.date: When, in microseconds since 1 January 1970 (UTC).

How to open it

Free, in OpenExtract. Open the backup in OpenExtract and choose Web history. Timeline uses it too. OpenExtract reads both Firefox files and lists their visits with Safari's. Step by step: Export Safari and Firefox history.

By hand. In a backup that isn't encrypted, 2e/2e57c396a35b0d1bcbc624725002d98bd61d142b is an ordinary SQLite database with no extension. Copy it out of the backup folder and open the copy with any SQLite browser, such as DB Browser for SQLite. Work on a copy: changing anything inside a backup can stop it from restoring.

In an encrypted backup, the file in the backup folder is encrypted with a key of its own, which only the backup password unlocks, so nothing can open it until it's decrypted. OpenExtract does that when you open the backup and type its password.
