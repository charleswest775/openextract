What it holds

ChatStorage.sqlite is WhatsApp's own database, in its shared app group. Each chat is a row in ZWACHATSESSION and each message a row in ZWAMESSAGE. Photos, videos, voice messages and documents are separate files in the same domain, and ZWAMEDIAITEM says where each one is.

Its layout follows WhatsApp's version, not the iOS version. Two things catch people out: put a chat in order by ZSORT, the order messages arrived on the phone, because ZMESSAGEDATE comes from the sender's clock; and reactions aren't rows of their own, they're stored with the message they react to.

Key columns

  • ZWACHATSESSION.ZCONTACTJID: Who the chat is with: a WhatsApp ID such as <number>@s.whatsapp.net, or a group's ID.
  • ZWACHATSESSION.ZPARTNERNAME: The chat's name as WhatsApp shows it.
  • ZWAMESSAGE.ZTEXT: The message text.
  • ZWAMESSAGE.ZISFROMME: 1 if the phone's owner sent it.
  • ZWAMESSAGE.ZMESSAGEDATE: When it was sent, by the sender's clock, in seconds since 1 January 2001 (UTC).
  • ZWAMESSAGE.ZSORT: Its place in the chat, in the order it arrived on the phone.
  • ZWAMEDIAITEM.ZMEDIALOCALPATH: Where the photo, video or other file is, relative to WhatsApp's folder.

How to open it

Free, in OpenExtract. Open the backup in OpenExtract and choose WhatsApp. Timeline uses it too. OpenExtract shows each chat with its photos, voice messages, replies, reactions and calls, and saves chats as a web page, PDF, CSV or text. Step by step: Export WhatsApp chats from an iPhone backup.

By hand. In a backup that isn't encrypted, 7c/7c7fba66680ef796b916b067077cc246adacf01d is an ordinary SQLite database with no extension. Copy it out of the backup folder and open the copy with any SQLite browser, such as DB Browser for SQLite. Work on a copy: changing anything inside a backup can stop it from restoring.

In an encrypted backup, the file in the backup folder is encrypted with a key of its own, which only the backup password unlocks, so nothing can open it until it's decrypted. OpenExtract does that when you open the backup and type its password.

Related files

  • LID.sqlite: WhatsApp's LIDs, the IDs newer WhatsApp versions use instead of phone numbers, matched to numbers and names.
  • ContactsV2.sqlite: WhatsApp's copy of the address book, from older WhatsApp versions: names for the numbers in your chats.
  • group.net.whatsapp.WhatsApp.shared.plist: WhatsApp's shared settings, including the phone's own WhatsApp ID and profile name.
  • sms.db: The Messages database: every text and iMessage, who it was with, when, and which attachments go with it.
