What each iOS update changed for iPhone backups

The current version is iOS 27.2.1, released on November 9, 2026, and iOS 27.3 is in beta. Apple's notes for iOS 27 don't mention any change to backups, apart from two security fixes in a part of iOS called MobileBackup. Below is each release, newest first: what changed for backups in Apple's words, and whether OpenExtract has tested backups from it.

We make OpenExtract, a free iPhone backup viewer. Every fact here about Apple's software links to Apple's own page, checked on November 22, 2026. "Tested" means backups from that iOS version are in OpenExtract's automated checks; how we test explains which ones.

The Apple Devices app on Windows

On a Windows PC, Apple's own instructions for backing up an iPhone start with the Apple Devices app, and use iTunes only if the PC doesn't have it. Apple Devices comes from the Microsoft Store, which keeps it up to date.

Its user guide describes the same choices Finder gives on a Mac: back up to iCloud or to the computer, tick Encrypt local backup to protect the backup with a password, then Back Up Now. It can back up over a cable or over Wi-Fi. One choice matters for what you can get back later: only an encrypted backup includes saved passwords, Wi-Fi settings, website history, Health data and call history.

To find the backups on a PC, Apple says to look in %USERPROFILE%\Apple\MobileSync\Backup, or in %AppData%\Apple Computer\MobileSync\Backup if that folder doesn't open. Where iPhone backups are stored has the folders on a Mac too, and how to keep a backup safe. OpenExtract finds backups in those folders on its own. On Windows it can also make a backup through Apple Devices, and offers to install it if the PC has neither Apple Devices nor iTunes.

How we test

OpenExtract is free and open source, made by an independent developer with help from contributors. Its checks run on two kinds of backup.

  • Real backups. Public test backups that forensic researchers made from real iPhones and published with their passwords: iOS 13.3.1, 13.4.1, 15.3.1, 16.1.2 and 17.3. The checks open each one, compare what OpenExtract shows with the raw databases so nothing is silently dropped, and look for specific events from the researchers' own logs of what they did on the phone.
  • Generated backups. Made-up people's phones, written by our own generator, with an answer key for what a correct reader should show. They use database layouts taken from real backups of iOS 15.3.1 and 17.3, and from Apple's iOS 26.5 Simulator for iOS 26. Apple's Simulator gives the layouts for Messages, Contacts, Photos, Safari, Calendar and Voice Memos. For call history, Notes, voicemail and the backup's own index, the iOS 26 backups use iOS 17.3 layouts. Separate generated backups, checked on every change to the code, cover the older formats of iOS 6 to 10.1.

The real backups and the generated ones are checked before every release, on Windows, Mac and Linux. The most recent run passed on all three. We ran the same checks again on a Mac on November 22, 2026, against the current code, and they passed. The test setup is public: see the corpus folder on GitHub.

New releases go on this page after we've read Apple's notes for them. A version moves to tested only once a backup from it is in these checks.

Questions

Does iOS 27 change iPhone backups?

Not in any way Apple describes. Apple's update notes for iOS 27, 27.0.1, 27.2 and 27.2.1 don't mention backups. The iOS 27 security notes list two fixes in a component called MobileBackup, and Apple says nothing about the backup format changing. You back up the same way as before: Finder on a Mac, the Apple Devices app or iTunes on Windows.

Can OpenExtract open a backup from iOS 27?

No iOS 27 backup is in OpenExtract's tests yet, so we can't promise it. OpenExtract opens any backup folder that has a Manifest.db file in it, so try it. If something is missing or wrong, open an issue on GitHub or use Help in the app.

Which iOS versions has OpenExtract tested?

Real backups from iOS 13.3.1, 13.4.1, 15.3.1, 16.1.2 and 17.3 are checked before every release. Generated backups cover iOS 15, 17 and 26 (with iOS 26.5's database layouts), plus older backup formats from iOS 6 to 10.1. iOS 11, 12, 14, 18 and 27 aren't tested yet.

Where does the Apple Devices app save iPhone backups?

Apple's instructions say to look in %USERPROFILE%\Apple\MobileSync\Backup, and if that folder doesn't open, in %AppData%\Apple Computer\MobileSync\Backup. Apple Devices and iTunes keep their backups in one of these. Where iPhone backups are stored has the details.
