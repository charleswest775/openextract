What it holds

NoteStore.sqlite is the Notes app's database, in its shared app group. Notes, folders and accounts are all rows in one table, ZICCLOUDSYNCINGOBJECT.

A note's text isn't plain text. It's in ZICNOTEDATA.ZDATA, compressed with gzip and stored in Apple's own protobuf format, so a SQLite browser shows only a blob. ZSNIPPET has the first line or so as plain text.

Before iOS 9, notes were in notes.sqlite instead.

Key columns

  • ZICCLOUDSYNCINGOBJECT.ZTITLE1: A note's title. Rows that are folders or accounts leave it empty.
  • ZICCLOUDSYNCINGOBJECT.ZSNIPPET: The start of the note, as plain text.
  • ZICNOTEDATA.ZNOTE: Which note the text belongs to: its Z_PK in ZICCLOUDSYNCINGOBJECT.
  • ZICNOTEDATA.ZDATA: The note's text, gzip-compressed protobuf.

Tables by iOS version

iOS 13.3.1 has 11 tables:

ACHANGE, ATRANSACTION, ATRANSACTIONSTRING, ZICCLOUDSTATE, ZICCLOUDSYNCINGOBJECT, ZICLOCATION, ZICNOTEDATA, ZICSERVERCHANGETOKEN, Z_METADATA, Z_MODELCACHE, Z_PRIMARYKEY

Then, version by version:

  • iOS 13.4.1 (11 tables): the same as iOS 13.3.1.
  • iOS 15.3.1 (11 tables): the same as iOS 13.4.1.
  • iOS 16.1.2 (13 tables): adds ZICINVITATION, ZICNOTEPARTICIPANT.
  • iOS 17.3 (13 tables): the same as iOS 16.1.2.

The iOS 16.0 backup is encrypted with a password that isn't public, so only its list of files was checked, not its tables.

How to open it

Free, in OpenExtract. Open the backup in OpenExtract and choose Notes. Timeline uses it too. OpenExtract unpacks the note text and saves notes as PDF or plain text. Step by step: Export notes from an iPhone backup.

By hand. In a backup that isn't encrypted, 4f/4f98687d8ab0d6d1a371110e6b7300f6e465bef2 is an ordinary SQLite database with no extension. Copy it out of the backup folder and open the copy with any SQLite browser, such as DB Browser for SQLite. Work on a copy: changing anything inside a backup can stop it from restoring.

In an encrypted backup, the file in the backup folder is encrypted with a key of its own, which only the backup password unlocks, so nothing can open it until it's decrypted. OpenExtract does that when you open the backup and type its password.
