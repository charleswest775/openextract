How it works

Four steps. No phone needed.

Works even if your phone is broken, lost, or long gone. All you need is a backup somewhere on a computer.
01
Find or create your backup

If you've ever plugged an iPhone into this computer, a backup is probably already on it and OpenExtract finds it automatically. If not, plug in your phone and make one — Finder on Mac, iTunes on Windows.

02
Unlock if needed

Encrypted backups need the password you set. OpenExtract handles this on your laptop; the password never leaves it.

03
Browse what's in there

Messages, WhatsApp, photos, contacts, calls, notes and voicemail on one page. Search all of it from one box. Nothing you click changes the backup.

04
Save what you want

Text threads as PDF, photos as originals, and the rest as everyday files, in a folder you choose.

A plain-English promise

OpenExtract is open source — anyone can read the code. There's no account, and it doesn't know who you are. It goes online for only two things: to check for a newer version, if you say yes, and to send a feedback report when you click Send. Nothing from your backup goes with either. FAQ

Questions people
ask all the time.

Can't find yours? There's a real human in the GitHub discussions who'll answer.

Does OpenExtract work if my phone is broken?

Yes. You don't need the phone at all — just a backup sitting on a computer you own. Any iTunes or Finder backup will do, even years-old ones.

Is it really free? What's the catch?

No catch. It's MIT-licensed open source, built in the open by an independent developer. There's no account, no trial, no paid tier and nothing to upgrade to. It's free, with no strings attached. The code is public on GitHub if you want to verify. Coming from iMazing? Here's what the free iMazing alternative covers, and where iMazing still wins.

Can it read encrypted backups?

Yes, as long as you know the password. Encrypted backups actually contain more data (saved passwords, Safari history), so they're usually the better choice when you have the option.

What formats can I export to?

Messages and WhatsApp chats as PDF, HTML, CSV, or plain text (here’s how to export WhatsApp chats). Photos as originals (HEIC, JPEG, MOV). Contacts as vCard or CSV. Each time you save, you choose where the files go.

Will Apple know I'm using this?

No. OpenExtract only reads files that are already on your computer. It never talks to Apple's servers or your iCloud.
