What it holds

CallHistory.storedata is the database behind the Recents list in the Phone app. It's a SQLite file made by Core Data, so its tables start with Z: each call is a row in ZCALLRECORD.

Phone calls and FaceTime calls are both here; ZSERVICE_PROVIDER says which service carried each one.

Library/CallHistoryDB/CallHistoryTemp.storedata (81b7fe4b60b1d80e04b158a642b68803d982987d): A second store with the same ZCALLRECORD table. OpenExtract reads both and skips calls it has already seen. We saw it next to CallHistory.storedata in iOS 13.3.1, 13.4.1, 15.3.1, 16.1.2 and 17.3.

Key columns

  • ZCALLRECORD.ZADDRESS: The other party's number or address.
  • ZCALLRECORD.ZDATE: When the call started, in seconds since 1 January 2001 (UTC).
  • ZCALLRECORD.ZDURATION: How long it lasted, in seconds.
  • ZCALLRECORD.ZORIGINATED: 1 for a call made from the phone, 0 for one it received.
  • ZCALLRECORD.ZANSWERED: Whether an incoming call was answered.
  • ZCALLRECORD.ZSERVICE_PROVIDER: Which service carried it, such as com.apple.Telephony or com.apple.FaceTime.

Tables by iOS version

The same 7 tables in every backup we opened (iOS 13.3.1, 13.4.1, 15.3.1, 16.1.2 and 17.3):

ZCALLDBPROPERTIES, ZCALLRECORD, ZHANDLE, Z_2REMOTEPARTICIPANTHANDLES, Z_METADATA, Z_MODELCACHE, Z_PRIMARYKEY

The iOS 16.0 backup is encrypted with a password that isn't public, so only its list of files was checked, not its tables.

How to open it

Free, in OpenExtract. Open the backup in OpenExtract and choose Calls. People and Timeline use it too. OpenExtract lists every call with names from the address book, adds FaceTime calls from sms.db, and saves the list as CSV. Step by step: Export iPhone call history.

Always encrypted on disk. This file is only in encrypted backups, so the copy in the backup folder is encrypted with a key of its own, which only the backup password unlocks. Nothing can open it until it's decrypted. OpenExtract does that when you open the backup and type its password.

Related files

  • voicemail.db: Visual Voicemail: who left each voicemail, when, and how long it is. The audio is in separate files.
  • sms.db: The Messages database: every text and iMessage, who it was with, when, and which attachments go with it.
  • AddressBook.sqlitedb: The Contacts database: each contact's name, company, phone numbers, email addresses and notes.
