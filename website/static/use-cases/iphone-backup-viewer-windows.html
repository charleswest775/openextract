A free iPhone backup viewer
for Windows.

OpenExtract is a free, open-source app for Windows 10 and 11 that opens the iPhone backups iTunes and the Apple Devices app make, and shows what's inside: messages, photos, contacts, call history, notes, voicemails and Safari history. No account and no trial, and the backup stays on your PC.

What you can see

  • Messages: every iMessage, SMS and group chat, with the photos sent in them, plus search.
  • Photos: the camera roll and the albums made on the phone.
  • Contacts, Calls and Notes: the address book, the call log including FaceTime, and Apple Notes.
  • Voicemail: saved voicemails you can play and export.
  • History: Safari visits and the sites visited most.
  • Overview and Timeline: counts and patterns for the whole backup, and everything in one list by date.

You can see each of these on the screenshots page, taken with a made-up test backup.

01

Download and install

Download OpenExtract for Windows and run the installer. It's signed by Charles West, the developer, and installs for your Windows user only.

02

Open a backup

Choose Explore my data and pick the backup folder, usually %USERPROFILE%\Apple\MobileSync\Backup (the Apple Devices app, or iTunes from the Microsoft Store) or %APPDATA%\Apple Computer\MobileSync\Backup (iTunes downloaded from Apple's website). Not sure where yours is? Here's how to find it.

03

Unlock it if it's encrypted

Encrypted backups show a lock. Type the password you set when you turned on encryption. Encrypted backups hold more of the phone's data.

04

Browse

Use the tabs along the side: Overview, Timeline, Messages, Photos, Contacts, Calls, Notes, Voicemail and History.

05

Export what you need

Messages save as HTML, CSV or text. Photos and voicemail audio save as files, and calls, contacts and history save as CSV.

What it can't do

  • No iCloud backups. It opens backups saved on a computer.
  • It doesn't edit or restore. It reads backups. It can't change one or put it back on a phone.
  • Not every app. It covers Apple's own apps listed above. Chat apps such as WhatsApp aren't supported.
  • Encrypted backups need their password. There's no way around a forgotten one.
  • It reads backups, it doesn't manage the phone. For a full side-by-side, see OpenExtract vs iMazing.

Common questions

Does it work with backups from the Apple Devices app? Yes. Apple Devices and iTunes make the same kind of backup, and OpenExtract opens both.

Which iOS versions does it read? The project tests it every week against real public backups from iOS 13 through 17.

Is it safe to install? The installer is signed by the developer, and all of the code is public on GitHub for anyone to read. It doesn't upload your backup.

Does it work on Mac and Linux too? Yes. There are versions for Mac (Apple Silicon) and Linux as well.

Does anything get uploaded? No. OpenExtract reads the backup on your own computer and doesn't send it anywhere. The only thing it asks the internet for is whether a new version is out, and it asks you before it checks. You can turn that off in Settings.

Is it really free? Yes. OpenExtract is open source under the MIT license, with no paid tier, no account and no strings attached. The code is on GitHub.
