Check an iPhone for
known spyware.

Amnesty International's Mobile Verification Toolkit (MVT) is a free tool that looks through an iPhone backup for traces of known spyware, such as NSO Group's Pegasus. It works best on an encrypted backup. OpenExtract, also free, makes one in a few clicks on a Mac, a Windows PC or Linux. Here's how to use the two together, and how to read the result honestly.

We make OpenExtract. We don't make MVT and aren't connected to Amnesty International. The facts about MVT here come from its own documentation, checked on November 22, 2026, and every MVT command on this page was run with MVT 2026.11.2 on a test backup. It's all listed under Sources.

Before you start

  • MVT is built for experts. Its makers describe it as a forensic tool for technologists and investigators that needs the command line, and say it isn't meant for people checking their own phone. If you're at home in a terminal, the steps below work. If you're worried and the terminal isn't for you, go straight to where to get help.
  • It only finds what's already known. MVT compares the backup with published lists of indicators: website addresses, file names and app IDs tied to spyware that researchers have caught. MVT's own docs warn that these public lists can miss recent traces. A clean result isn't proof.
  • Most people are never targeted. Apple says the vast majority of iPhone users will never face a mercenary spyware attack. These attacks aim at a very small number of people, often journalists, activists, politicians and diplomats.
  • Only your own phone, or with consent. MVT's license allows it to be used only with the explicit consent of the person whose data is checked.

What you'll need: the iPhone and its cable; a Mac with Apple Silicon, a Windows 10 or 11 PC, or a Linux PC; about half an hour for the backup; and some comfort typing commands in a terminal.

01

Install OpenExtract

Free for Mac (Apple Silicon), Windows 10 and 11, and Linux. Download it here. No account, no trial, no card.

Already have an encrypted backup made with Finder, iTunes or the Apple Devices app? MVT reads those too. Skip to step 03 and use that backup's folder (here's where to find it).

02

Make an encrypted backup

Plug the iPhone into the computer with a cable and unlock it. In OpenExtract, click Back up my iPhone.

Under 1. Select device, click your iPhone. If the iPhone asks Trust This Computer?, tap Trust and enter its passcode. Under 2. Backup destination, click Choose... and pick an empty folder, such as a new folder called iphone-backup in your home folder. Under 3. Encryption, tick Encrypt backup and type a password where it says Set a backup password. Write it down: MVT needs it, and it can't be recovered.

Click Start Backup. When the iPhone asks for its passcode, enter it there. Keep the iPhone connected and unlocked until OpenExtract says Backup complete! and shows the backup's folder: a folder inside the one you chose, named with a long ID for your iPhone.

If the iPhone already has a backup password, set earlier in Finder, iTunes or OpenExtract, the box is already ticked and OpenExtract says so. The backup uses that password, and that's the one MVT will need. When the backup is done, OpenExtract opens it and asks for the password. Typing it and clicking Unlock is a quick way to check you have the right one.

On Windows, if OpenExtract says it needs Apple Devices, click Install Apple Devices (Apple's free app, from the Microsoft Store), then Check again. On Linux, install usbmuxd first: sudo apt install usbmuxd on Ubuntu or Debian.

Under the hood, OpenExtract makes the backup with pymobiledevice3, the open-source tool MVT's docs use for backups, and asks the iPhone for a full backup, as MVT's instructions do.

03

Install MVT

MVT runs in a terminal and needs Python 3.11 or newer (python3 --version tells you which you have). What to install first depends on the computer:

Mac: MVT's docs use Homebrew for Python and say Xcode is needed too.

brew install python3

Linux:

sudo apt install python3 python3-venv python3-pip sqlite3

Windows: MVT doesn't officially support running directly on Windows. Its docs recommend Windows Subsystem for Linux (WSL). Microsoft's steps: open PowerShell as administrator, run wsl --install, and restart. Then open Ubuntu, the Linux it installs, and follow the Linux steps from here on.

Then, on any of the three, install MVT in a folder of its own:

python3 -m venv mvt-env
source mvt-env/bin/activate
pip install mvt

In a new terminal window, run source mvt-env/bin/activate again before using MVT. (MVT's docs also offer pipx install mvt, which does the same in one step once pipx is installed.)

04

Download the latest indicators

mvt download-iocs

This fetches the public indicator lists MVT's maintainers collect from Amnesty International and other researchers, and MVT uses them automatically from then on. When we ran it on November 22, 2026, it downloaded 19 lists with 11,494 indicators in all, among them NSO Group's Pegasus, Predator, Operation Triangulation and a list of stalkerware. Run it again before each check to get the newest lists.

05

Decrypt a copy of the backup

mvt-ios decrypt-backup -d ~/mvt-decrypted ~/iphone-backup/YOUR-IPHONE-ID

Replace YOUR-IPHONE-ID with the folder name OpenExtract showed; ls ~/iphone-backup lists it. In WSL on Windows, the C: drive is under /mnt/c, so a backup in C:\Users\YOUR-NAME\iphone-backup is at /mnt/c/Users/YOUR-NAME/iphone-backup.

MVT asks Enter backup password: and shows a star for each character you type. It writes a decrypted copy to mvt-decrypted and leaves the backup itself as it was. That copy has no password on it: your messages, contacts and the rest are in plain files. Keep it on your own computer, and delete it when you're done.

06

Run the check

mvt-ios check-backup --output ~/mvt-results ~/mvt-decrypted

MVT reads the decrypted copy, module by module (messages, Safari history, calls, WhatsApp, configuration profiles and more), and compares what it finds with the indicators. Lines saying a module "produced no detections" are what you hope to see. "There might be no data to extract" is normal too: that app or file just isn't in this backup.

At the end, a box counts the alerts: informational, low, medium, high and critical. The mvt-results folder gets a file for each kind of record and a timeline.csv. Anything that matched an indicator is also saved in a file ending in _detected.json.

07

Read the result, then tidy up

No alerts means none of today's public indicators matched. That's worth knowing, but it isn't a clean bill of health, and MVT says so itself when it finds nothing. If you have a real reason to worry, such as a threat notification from Apple, ask for expert help anyway.

An alert means something in the backup matched a known indicator, such as a website address tied to Pegasus. It's a reason to get help, not a verdict on its own: MVT's own message says only an expert's review can confirm whether it's a sign of an attack. Keep the backup and the mvt-results folder, don't reset the iPhone, and contact one of the helplines below. MVT's docs warn that resetting the iPhone's settings can remove traces an expert would look for. If the alert points to a text message or a page in Safari history, you can open the same backup in OpenExtract and read it there, with the rest of the conversation.

When you're done, delete mvt-decrypted. Keep the backup or delete it, as you like. OpenExtract never changes it.

Where to get help

  • If Apple sent you a threat notification. Apple says these are high-confidence alerts that someone was targeted by mercenary spyware, and should be taken very seriously. It suggests expert help, such as Access Now's Digital Security Helpline, and turning on Lockdown Mode. Apple's notifications never ask you to click a link or give your Apple Account password. To check one is real, sign in at account.apple.com; a real one shows at the top of the page.
  • Access Now's Digital Security Helpline. Free, around the clock, in 10 languages, and it answers within two hours. It helps civil society: activists, journalists, bloggers, media organizations and human rights defenders. It checks first that a request is one it can take on.
  • Amnesty International's Security Lab. The team behind MVT. It supports journalists, activists and civil society organizations at risk from targeted digital attacks. Its Get Help page leads to a Digital Security Resource Hub of helplines and guides, and to a way to contact the Lab securely.
  • If you're worried about someone you know, such as a partner or an ex with access to your phone or accounts: Apple's Personal Safety User Guide walks through securing your accounts and devices and cutting digital ties, including Safety Check on iOS 16 and later.

If MVT stops with a message

  • The backup appears to be encrypted. Please decrypt it first: check-backup was pointed at the backup itself. Do step 05, then point check-backup at ~/mvt-decrypted.
  • Failed to decrypt backup. Password is probably wrong.: try again with care. If the iPhone already had a backup password, it's that one, not a new one.
  • "command not found" for mvt or mvt-ios: the folder MVT is installed in isn't active in this window. Run source mvt-env/bin/activate from the folder where you made it.
  • This phone is running an outdated iOS version: a warning, not an alert. MVT compares the backup's iOS version with the newest one. Updating the iPhone is worth doing either way.

Common questions

Does OpenExtract check for spyware itself? No. OpenExtract makes and opens iPhone backups. The checking is done by MVT, the Mobile Verification Toolkit from Amnesty International's Security Lab.

Does a clean result mean my iPhone is safe? No. MVT looks only for indicators that have already been published. Its documentation warns that public indicators can miss recent traces and give a false sense of security. If you have reason to worry, get expert help even after a clean result.

Why does the backup need to be encrypted? MVT's documentation recommends encrypted backups because they contain more data than unencrypted ones, such as Safari history. MVT can read an unencrypted backup too, but it has less to check. We wrote more about what encrypted backups hold.

Can I check someone else's iPhone? Only with their explicit consent. MVT's license allows it to be used only with the explicit consent of the person whose data is being checked.

Does anything get uploaded? OpenExtract reads and makes the backup on your own computer and doesn't send it anywhere. MVT also runs on your computer. It goes online to download indicator lists and check for updates, and while checking it follows known short links to see where they lead, unless you start the command with MVT_NETWORK_ACCESS_ALLOWED=false.

Does this work on Windows? OpenExtract makes the backup on Windows 10 and 11. MVT doesn't officially support running directly on Windows; its documentation recommends Windows Subsystem for Linux (WSL), following the Linux steps.

Is it free? Yes. OpenExtract is open source under the MIT license, with no paid tier and no account. The code is on GitHub. MVT is free from PyPI under its own license, an adaptation of the Mozilla Public License with a consent clause.

Sources

What we ran: on November 22, 2026 we installed MVT 2026.11.2 from PyPI in a Python 3.12 virtual environment on a Mac, ran mvt download-iocs, and ran decrypt-backup and check-backup on an encrypted test backup of a made-up person, made with the same generator OpenExtract's own tests use. We added the file OpenExtract leaves in a backup folder when a backup finishes, so the folder looked like one the app makes. MVT decrypted it, ran its 28 backup modules, read 1,284 messages, 357 Safari history entries and 166 calls, and reported no alerts, as expected for a backup with no spyware in it. On a copy with a known Pegasus web address added to Safari history, it reported one critical alert and wrote safari_history_detected.json. We haven't yet run MVT on a backup OpenExtract made from a real iPhone; the OpenExtract steps and button names come from the app itself (version 0.18.0).
