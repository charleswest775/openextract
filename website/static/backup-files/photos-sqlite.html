What it holds

Photos.sqlite is the index of the photo library. It doesn't hold the pictures: those are separate files under Media/DCIM/ in CameraRollDomain.

Each photo or video is a row in ZASSET, called ZGENERICASSET before iOS 14, with its folder and file name in ZDIRECTORY and ZFILENAME. Albums are in ZGENERICALBUM.

A photo kept only in iCloud, with Optimize iPhone Storage turned on, can have a row here but no file in the backup.

Key columns

In iOS 13.3.1 and 13.4.1, ZASSET is called ZGENERICASSET, with the same columns.

  • ZASSET.ZDIRECTORY: The folder under Media/DCIM/ the file is in, such as 106APPLE (older versions write DCIM/106APPLE).
  • ZASSET.ZFILENAME: The file's name, such as IMG_0001.HEIC.
  • ZASSET.ZDATECREATED: When it was taken, in seconds since 1 January 2001 (UTC).
  • ZASSET.ZFAVORITE: 1 for a favorite.
  • ZASSET.ZHIDDEN: 1 for a photo in the Hidden album.
  • ZASSET.ZTRASHEDSTATE: 0 for a photo in the library; anything else means it's in Recently Deleted.

How to open it

Free, in OpenExtract. Open the backup in OpenExtract and choose Photos. Timeline uses it too. OpenExtract shows the library with its albums, favorites and hidden photos, and copies the originals to your computer. Step by step: Extract photos from an iPhone backup.

By hand. In a backup that isn't encrypted, 12/12b144c0bd44f2b3dffd9186d3f9c05b917cee25 is an ordinary SQLite database with no extension. Copy it out of the backup folder and open the copy with any SQLite browser, such as DB Browser for SQLite. Work on a copy: changing anything inside a backup can stop it from restoring.

In an encrypted backup, the file in the backup folder is encrypted with a key of its own, which only the backup password unlocks, so nothing can open it until it's decrypted. OpenExtract does that when you open the backup and type its password.
