View an iPhone backup
on Windows.

Windows keeps iPhone backups in a folder called MobileSync\Backup: either %USERPROFILE%\Apple\MobileSync\Backup (the Apple Devices app, or iTunes from the Microsoft Store) or %APPDATA%\Apple Computer\MobileSync\Backup (iTunes downloaded from Apple's website). The files inside aren't readable on their own, so open the folder with a backup viewer. OpenExtract is a free, open-source one for Windows 10 and 11.

You'll find the folder in a minute. What's in it will look like nonsense, and that's normal: Apple renames every file in a backup to a long code and keeps a database that maps the codes back to real names. A viewer reads that database for you and shows the backup much as you saw it on the phone.

This guide is for Windows. On a Mac or Linux, see the free iPhone backup viewer.

01

Open the backup folder

Press the Windows key and R together, paste %USERPROFILE%\Apple\MobileSync\Backup and press Enter. If Windows can't find it, try %APPDATA%\Apple Computer\MobileSync\Backup. If neither exists, this PC has no iPhone backup in the usual place.

02

Recognize a backup, and leave it as it is

Each backup is one folder with a long name of letters and numbers, which is the device's ID. Inside are files called Manifest.db, Info.plist and Status.plist, and many folders with two-character names. The folder's date modified tells you roughly when it was last backed up. Don't rename, open or edit anything inside it. To move or keep a copy, copy the whole folder, for example to an external drive.

03

Install OpenExtract

Download OpenExtract for Windows and run the installer. It's free, needs no account, and installs for your Windows user only. The installer is signed by Charles West, the developer.

04

Open the backup in OpenExtract

On OpenExtract's start screen, choose to open a backup folder, and pick the Backup folder or one backup folder inside it. If there's more than one, OpenExtract lists each with the device name, iOS version and date. A lock means the backup is encrypted: type the password you set when you turned on encryption.

05

Read it, and save what you need

Pick what to look at: messages, photos, contacts, calls, notes, voicemail or web history. The Timeline puts messages, calls, photos, notes and more in one list by date. Conversations save as PDF (with their photos), HTML, CSV or text, contacts as CSV, and photos and voicemails as files.

What you can see

  • Messages: every iMessage, SMS and group chat, with the photos sent in them. You can search them too.
  • Photos: the camera roll and the albums made on the phone.
  • Contacts, calls and notes: the address book, the call log including FaceTime, and Apple Notes.
  • Voicemail: saved voicemails you can play and save.
  • Web history: pages visited in Safari and Firefox, and the sites visited most.
  • Timeline: messages, calls, photos and more in one list by date.
  • Backup details: counts and patterns for the whole backup, under Tools on the home page.

Some things, such as call history and web history, are only in encrypted backups. You can see each screen on the screenshots page, taken with a made-up test backup.

What it can't do

  • iCloud backups aren't on your PC. OpenExtract reads backups saved on a computer.
  • It reads backups and can make new ones; it doesn't edit or restore them. It can't change a backup or put one back on a phone. For a full side-by-side, see OpenExtract vs iMazing.
  • Not every app. It covers the apps listed above. Chat apps such as WhatsApp aren't supported.
  • Encrypted backups need their password. There's no way to open one without it.
  • An interrupted backup may be incomplete. If a backup stopped partway, some things may be missing. Back up again to get a full one.
  • It doesn't change where iTunes or Apple Devices save backups. Apple's apps always use their usual folder. OpenExtract can open a copy from anywhere, though, and a backup it makes itself goes to the folder you choose.

Common questions

Does it work with backups from the Apple Devices app? Yes. Apple Devices and iTunes make the same kind of backup, and OpenExtract opens both.

Why can't I just open the files in the backup? Apple stores the data in databases and renames every file to a code, so there's nothing to double-click. A viewer reads the database and shows the real content.

Can I move the backup to another drive? You can copy the whole folder anywhere and open the copy in OpenExtract. Apple's apps only look in their usual folder, so leave the original there if you want them to keep using it.

Which backup belongs to which phone? OpenExtract shows each backup's device name, iOS version and date when you pick the folder that holds them.

Does it open iPad backups? Yes. iPad backups use the same format, so OpenExtract opens them the same way. Things an iPad doesn't have, such as voicemail, won't show up.

Which iOS versions does it read? Before a release, the project tests it on Windows, Mac and Linux against real public backups from iOS 13 to 17. Every change is also tested with made-up backups laid out like iOS 15, 17 and 26.

Is it safe to install? The installer is signed by the developer, and all of the code is public on GitHub for anyone to read. It doesn't upload your backup.

Does it work on Mac and Linux too? Yes. There are versions for Mac (Apple Silicon) and Linux as well. See the free iPhone backup viewer and iPhone backups on Linux.

Does anything get uploaded? No. OpenExtract reads the backup on your own computer and doesn't send it anywhere. The only thing it asks the internet for is whether a new version is out, and it asks you before it checks. You can turn that off in Settings.

Is it really free? Yes. OpenExtract is open source under the MIT license, with no paid tier, no account and no strings attached. The code is on GitHub.
